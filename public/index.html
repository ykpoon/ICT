單元 1：網絡基礎

🌐 探索互聯網世界：電腦網絡與設備

電腦網絡是由多台設備連接組成的系統，讓資料、資源與服務能夠彼此傳遞與共享。本頁將帶你掌握 LAN/WAN 分別、核心硬件運作，以及 IP 與 MAC 地址的秘密！

網絡覆蓋範圍：LAN vs WAN

局域網 (LAN - Local Area Network)

地理範圍小（如單一房間、學校電腦室、住宅）

高傳輸速度
  • 典型範例：學校電腦室、家中 Wi-Fi 網絡
  • 核心優勢：資料傳輸速率極高、延遲低、安全性較佳
  • 連接方式：使用 Ethernet 乙太網絡纜線或 Wi-Fi

廣域網 (WAN - Wide Area Network)

地理範圍廣（跨越城市、國家甚至全球）

跨區域連接
  • 典型範例：全球互聯網 (Internet)、跨國企業專線
  • 核心功能：連接多個不同地理位置的 LAN 網絡
  • 連接方式：光纖海底電纜、衛星通訊、電訊商骨幹網

網絡核心硬件解密

交換機 (Switch)

負責 LAN 內部設備溝通

交換機就像區域快遞分配員，根據 **MAC 地址** 將數據精確送到同一 LAN 內的目標電腦，避免封包廣播碰撞。

工作層級：OSI 第 2 層 (Data Link)

路由器 (Router)

負責跨網絡數據路由尋路

路由器是互聯網的交通警察，根據 **IP 地址** 為封包選擇最佳傳送路徑，連接 LAN 與 WAN（如將家裡連至 Internet）。

工作層級：OSI 第 3 層 (Network)

無線存取點 (Wi-Fi AP)

提供無線訊號覆蓋

將有線網絡信號轉換為無線電波（Wi-Fi），讓手機、平板與筆記本電腦等裝置無需實體網線即可存取網絡。

工作層級：OSI 第 1-2 層 (Physical / Data Link)

尋址系統對比：MAC Address vs IP Address

🪪 MAC Address（物理地址）

全球唯一 / 實體燒錄
生活比喻：就像你的「香港身份證號碼」——出生即固定，全球獨一無二，跟隨設備一生不會改變。

由網卡製造商燒錄於硬體晶片中，格式為 12 個十六進位數字（例如：00:1A:2B:3C:4D:5E）。

🏠 IP Address（邏輯地址）

可變動 / 網絡位置
生活比喻：就像你的「寄信居住住址」——當你搬家或去學校/咖啡廳時，取得的地址會隨網絡環境改變。

用於網絡路由尋址。IPv4 格式（如 192.168.1.100）；IPv6 格式（如 2001:db8::1）。

Q1. 在學校電腦室中，負責連接所有電腦並根據 MAC 地址進行內部數據轉發的設備是？

💡 【教師導學提示】 Switch 工作於 OSI 第 2 層，依據 MAC 位址轉發；Router 則工作於第 3 層，依據 IP 位址路由。常犯錯誤是混淆 Switch 與 Router 的分工。

Q2. 下列關於 IP Address 與 MAC Address 的敘述，哪一項是正確的？

💡 【教師導學提示】 選項 C 為最佳生活化比喻。IPv4 是 32-bit (如 192.168.1.1)，IPv6 才是 128-bit。

Q3. 在 TCP/IP 4層模型中，HTTP、DNS 及 SMTP 屬於哪一層協定？

💡 【教師導學提示】 直接面對使用者應用程式的協定（如網頁瀏覽 HTTP、域名解析 DNS）均屬於應用層。
